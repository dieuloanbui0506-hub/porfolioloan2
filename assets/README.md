# Bui Dieu Loan - Hospitality Portfolio

Online portfolio website for Bui Dieu Loan — Guest Relation Officer & Hospitality Professional in Ho Chi Minh City.

## Tech Stack
- Pure HTML5, CSS3, Modern JavaScript (No heavy frameworks required)
- Multi-language support: English, Traditional Chinese (繁體中文), Vietnamese (Tiếng Việt)
- Dual theme support: Warm Champagne / Luxury Dark
- Contact Form: Connected to FormSubmit / Firebase Firestore
- Deployment: Vercel / GitHub Pages

## Project Structure
```
.
├── index.html        # Main landing page
├── styles.css        # Luxury styling, theme tokens & responsive layouts
├── script.js         # Language switcher, theme toggle, timeline filter & form handler
├── portfolio.md      # Resume / CV markdown dossier
└── assets/
    ├── Bui_Dieu_Loan_CV.pdf   # Downloadable CV PDF
    └── profile.jpg            # Portrait image
```
